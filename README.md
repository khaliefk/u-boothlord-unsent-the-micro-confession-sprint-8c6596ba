## What it does

`main.py` writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who the message was meant for, and the unsent line itself, exactly as it was typed and never sent.

## Run it

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`.
